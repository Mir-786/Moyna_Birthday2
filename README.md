# 3D Birthday Website (Vercel Ready)

Includes:
- **3D Parallax Perspective Scrolling Effect**
- **Vinyl Disk Animation & Tape Cards**
- **Live Elapsed Time / Age Counter**
- **Infinite Marquee Badges**
- **Celebration Confetti Button**

## Quick Run

```bash
npm install
npm run dev
```

Deploy directly on [Vercel](https://vercel.com) by connecting your repo. All config paths and image optimizations are pre-configured to build without errors.
